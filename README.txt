DR. JAMAL HUSSAIN SHAH — ACADEMIC PROFILE WEBSITE

CONTENTS
- index.html: responsive one-page academic website
- assets/Jamal_Hussain_Shah_CV.pdf: CV download linked from the website

QUICK PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.

FREE PUBLIC HOSTING (RECOMMENDED: GITHUB PAGES)
1. Sign in or create a free account at https://github.com/
2. Create a new public repository named: jamal-hussain-shah.github.io
3. Upload index.html and the entire assets folder (including the PDF) to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
6. Wait for deployment. The public address should be:
   https://jamal-hussain-shah.github.io/
   (It may take a few minutes to become available.)

ALTERNATIVE: NETLIFY DROP
1. Go to https://app.netlify.com/drop
2. Extract this ZIP.
3. Drag the extracted website folder (the folder containing index.html and assets/) into the drop area.
4. Netlify will provide a public URL. You can change the site name in its dashboard if available.

IMPORTANT BEFORE PUBLISHING
- This website includes a downloadable copy of the supplied CV. Review the CV for any personal details you do not want publicly indexed.
- The website intentionally does not display your phone/WhatsApp numbers by default.
- Check all publication metadata and update the selected list as needed. Google Scholar is linked for your full record.
- Replace the initials-only monogram with a professional headshot if desired. To do so, add a portrait image and update the hero section in index.html.
- GitHub Pages and Netlify provide a free hosted subdomain. A custom .com domain generally costs extra.
- Because the site is static HTML/CSS, there is no server or database to maintain.
